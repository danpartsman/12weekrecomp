# Old coaching system

Reference snapshot before the simple coaching redesign. These .txt files are archived source, not executable app files. Previous agreements, results, approvals and ledger entries remain in the database and immutable audit history. The active TEST flow uses SimpleSnapController and SimpleCoachingService. The old screens are reference-only while SimpleCoaching:Enabled is true. Restoring the previous system requires restoring its archived navigation and source, validating data compatibility, and then disabling the feature flag. No financial history is erased.
