# Old coaching system

Reference snapshot before the simple coaching redesign. These .txt files are archived source, not executable app files. Previous agreements, results, approvals and ledger entries remain in the database and immutable audit history. The active TEST flow uses SimpleSnapController and SimpleCoachingService. The old screens are reference-only while SimpleCoaching:Enabled is true. Set the flag false to restore the previous interface and assessment path. No financial history is erased.
